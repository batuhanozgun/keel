(`rol-<slug>/SKILL.md`) kurulumda GENESIS üretir (G3.3c; kalıp: `00_genesis/ROL_SKILL_KALIBI.md`).

dizindeki beceriler ancak yeniden başlatmayla görünür. Kurulumdan sonra bu alan [SERT]
korumadadır: beceri = rolün kafes tanımı, ajan kendi kafesini düzenleyemez.
